# AE2 Channel Tools

Невеликий адон для AE2: показує вільні канали та допомагає знайти пристрої, які втратили канал.

## Вимоги

- Minecraft **1.7.10** / Forge **10.13.4.1614**.
- Applied Energistics 2 — мінімум **rv3-beta-1080-GTNH**.

## Можливості

- **Вільні канали** — показує, скільки каналів ще доступно в мережі.
- **Сповіщення** — якщо після встановлення блока інші пристрої втратили канал, показує їхні координати та підсвічує на **15 секунд**. Відкриття GUI прибирає позначку.

## Встановлення

Поклади `ae2channeltools-0.1.0.jar` у `mods` **клієнта й сервера**, поруч із AE2.
Для одиночної гри достатньо встановити на клієнті.

## Використання

1. Прив'яжи **Network Visualiser** AE2 до мережі.
2. Тримай його в руці в режимі **Full** — числа показуватимуть вільні канали.
3. Команда **`/ae2channels`** перемикає між вільними й використаними каналами.

## Налаштування

У `config/ae2channeltools.cfg` можна вимкнути окремо сповіщення (`channelLossAlerts`) або вільні канали (`freeChannels`). За замовчуванням обидві функції ввімкнені.

## Збірка

Потрібен **JDK 17+**.

- Windows: `gradlew.bat build`
- Linux / macOS: `./gradlew build`
- Готовий JAR: `build/libs/ae2channeltools-0.1.0.jar`
