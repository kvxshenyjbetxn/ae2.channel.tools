# AE2 Channel Tools

Окремий аддон для Minecraft 1.7.10 / Forge 10.13.4.1614 та GTNH AE2.
Ціль першої версії: **Applied Energistics 2 rv3-beta-1082-GTNH**.
Проєкт не залежить від сусіднього checkout AE2: для збірки використовується опублікована dev-залежність Maven.

## Встановлення

Поклади `build/libs/ae2channeltools-0.1.0.jar` у `mods` **клієнта й сервера**, поруч із незміненим AE2.
В одиночній грі достатньо встановити на клієнті. Додатковий Mixin-завантажувач не потрібен:
точкові вставки використовують вбудований механізм Forge coremod.
Використовуй звичайний jar, а не `-dev` чи `-sources`.

## Сповіщення

Якщо встановлений гравцем AE2-блок або компонент спричиняє втрату каналів у вже підключених пристроїв,
гравець отримує повідомлення з координатами. Пристрої позначаються червоними миготливими рамками
та постійними лініями від прицілу на 15 секунд. Відкриття GUI прибирає позначку саме цього пристрою
з урахуванням виміру й сторони multipart-компонента.

Сповіщення надсилаються лише про втрату через нестачу місткості каналів, а не вимкнення живлення,
конфлікт контролерів або обмеження compressed/P2P-каналів. У чаті максимум 8 деталей плюс підсумок;
одночасно підсвічуються максимум 64 пристрої. Підтримуються мережі без контролера.

## Вільні канали

Використовуй **наявний Network Visualiser AE2**, прив'яжи його до мережі та тримай у руці в режимі **Full**.
Аддон змінює числа у цьому режимі на кількість додаткових каналів, доступних уздовж маршруту до контролера.
Нулі також показуються. Команда **`/ae2channels`** перемикає між вільними й використаними каналами локально.
Інші режими візуалізатора залишаються доступними. Перемикач діє до перезапуску клієнта.

У мережах без контролера враховується кількість потрібних каналів, а не лише успішно призначених:
після перевищення спільного ліміту 8 показується 0 вільних каналів. Multiblock споживає один канал;
при конфлікті compressed/P2P-каналів число вільних каналів не показується.

Дані оновлюються раз на 5 секунд; числа AE2 малює в радіусі 16 блоків. Аддон надсилає до 4096 найближчих
доступних ліній у радіусі 32 блоків і приховує застарілі дані через 10 секунд. Proxy-з'єднання й зв'язки
поза деревом маршрутизації не отримують числа місткості. Потрібен дозвіл BUILD системи безпеки ME-мережі.

## Налаштування

Після першого запуску: `config/ae2channeltools.cfg`.

```text
features {
    B:channelLossAlerts=true
    B:freeChannels=true
}
```

Коли AE2 уже містить відповідну функцію, аддон автоматично пропускає її вставки й повідомляє про це в логах.
Розпізнаються клас `appeng.me.ChannelAlertTracker` та поле `VLink.freeChannels` з наших реалізацій.

## Збірка

Потрібен JDK 17+ для Gradle; Minecraft-мод компілюється у байткод Java 8.
На цьому комп'ютері `build.bat` знаходить встановлений JDK 25. На інших системах задай `JAVA_HOME`
і виконай `gradlew.bat build` або `./gradlew build`.
Версію залежності можна задати через `-Pae2Version=rv3-beta-1082-GTNH`.

`gradlew.bat test` перевіряє втрату каналів, валідацію пакетів, місткість і перевантаження мережі без
контролера, облік multiblock, відбір найближчих ліній та порядок завантаження coremod після Forge
runtime deobfuscation. Вставки перевіряються на байткоді **опублікованого AE2**, включно з аналізом
стеків модифікованих методів і відмовою при відсутній точці інтеграції.

## Сумісність і перевірка у грі

Мод не замінює алгоритм розподілу каналів AE2 і не змінює його мережеві пакети.
Вставки залежать від внутрішньої структури конкретної версії AE2; інша версія потребує перевірки.
Якщо потрібні точки змінилися, запуск завершується з поясненням несумісності замість тихого застосування
частини патча. Видалення аддона повертає звичайну поведінку AE2; власних блоків або предметів у світі він не додає.

Для перевірки: підключи 8 пристроїв до звичайної гілки від контролера, додай дев'ятий ближче до нього
і перевір позначку пристрою, що втратив канал. Повтори у мережі без контролера. Перевір відкриття GUI,
окремі компоненти на одному блоці, перехід між вимірами, вимкнення живлення та обидва режими чисел.
Окремо перевір на dedicated server з однаковим аддоном на клієнті й сервері.
