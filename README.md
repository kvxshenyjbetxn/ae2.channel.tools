# AE2 Channel Tools

Аддон для GTNH AE2: показує вільні канали та сповіщає про їх втрату.

## Вимоги

- Minecraft **1.7.10** / Forge **10.13.4.1614**.
- Applied Energistics 2 **rv3-beta-1082-GTNH**.

## Можливості

### Вільні канали

- Показує доступні канали з урахуванням усього маршруту до контролера.
- Підтримує мережі без контролера та multiblock; при перевантаженні показує **0**.
- Оновлює дані раз на **5 секунд**. Потрібен дозвіл **BUILD** у ME-мережі.

### Алерти

- Якщо встановлення блока забирає канали в інших пристроїв, повідомляє гравця й показує координати.
- Червоні рамки та лінії від прицілу діють **15 секунд**; відкриття GUI прибирає позначку пристрою.
- Не спрацьовує через втрату живлення, конфлікт контролерів або compressed/P2P-обмеження.

## Встановлення

Поклади `ae2channeltools-0.1.0.jar` у `mods` **клієнта й сервера**, поруч із AE2.
Для одиночної гри — лише на клієнті. Використовуй звичайний JAR, не `-dev` чи `-sources`.
Mixin-завантажувач не потрібен.

## Використання

1. Прив'яжи **Network Visualiser** AE2 до мережі.
2. Тримай його в руці в режимі **Full** — числа показуватимуть вільні канали.
3. Командою **`/ae2channels`** перемикай вільні / використані канали до перезапуску клієнта.

## Налаштування

Файл після першого запуску: `config/ae2channeltools.cfg`. Обидві функції ввімкнені за замовчуванням.

```text
features {
    B:channelLossAlerts=true
    B:freeChannels=true
}
```

## Збірка

Потрібен **JDK 17+** і налаштований `JAVA_HOME`; мод сумісний із Java 8.

- Windows: `gradlew.bat build`
- Linux / macOS: `./gradlew build`
- Тести: `gradlew.bat test` або `./gradlew test`
- Готовий JAR: `build/libs/ae2channeltools-0.1.0.jar`

## Сумісність

- Не замінює алгоритм розподілу каналів і не додає блоків чи предметів.
- Розпізнає реалізації цих функцій із нашого форку AE2 та не дублює їх.
- Інші версії AE2 потребують перевірки; несумісні точки інтеграції зупиняють запуск із поясненням.
